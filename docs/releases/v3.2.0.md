# Crate 3.2.0

Crate 3.2.0 prepares the server for Crate Decks, the desktop DJ app built on Mixxx, and
ships Smart Mix analyzer v6, which reads keys, tempos and beat grids reliably. It has no
database migration. Profiles analysed with v5 stay in use until a Smart Mix backfill
campaign from Admin recomputes them with v6.

## Crate Decks

- **Native sign-in.** Decks signs in like Listen: email and password, or Google and
  Apple through the browser, with a refresh token and a 30-day session. The browser
  hands the code back on `http://127.0.0.1:<port>/callback` and the server accepts no
  other address. Each install keeps its own session, and Decks never receives cookies.
- **Capabilities.** `GET /api/capabilities` announces the Decks contract in a new
  `decks` section.
- **Which tracks have audio.** DJ search (`fields=dj`) tells each result whether its
  file can be streamed, as `playable`.
- **Contract.** A new page, Crate Decks, documents the server side of the contract,
  including what `beatPhaseOffsetMs` and `activeEndMs` mean.

## Smart Mix analyzer v6

- **Keys.** v5 read the kick and the bass as notes, so 81 % of tracks landed on 7B, 8A
  or 7A. v6 measures each semitone on its own band. On tracks where Mixxx's two key
  detectors agree, v6 matches them 83 % of the time, against 8 % for v5.
- **Tempos and grids.** A track that holds its tempo gets a constant grid and a whole
  or half BPM (128 instead of 128.346). Beats no longer jitter by about ±50 ms, and the
  bass catches grids that sit half a beat off.
- **Stricter `full`.** A profile is `full` only when its grid can be trusted, so fewer
  tracks get one. The planner still beatmatches `partial` profiles from their cue
  beats.
- **Faster.** Analysis takes 0.91 s per track instead of 1.17 s.
- **Upgrading.** Nothing is recomputed automatically. Smart playlists, sonic neighbours
  and collection insights keep reading v5 profiles until a Smart Mix backfill campaign
  from Admin replaces them with v6.

## Fixes

- **Access tokens on search.** The read plane no longer rejects VirtualDJ and
  automation `crv_` tokens on search and track reads when a proxy sends them there.
- **Library paths.** A path in a sibling directory whose name starts with the
  library's, or a symlink into one, no longer counts as inside the library.
- **Older paths.** Tracks stored under `/data/` stream through the API and VirtualDJ
  as they already did through the read plane.

## Downloads

- **Server:** `curl -fsSL https://cratemusic.app/install.sh | bash` for new home installs,
  or `crate install --dir <install folder>` to upgrade one. Binaries for Linux and macOS
  on amd64 and arm64 are attached, with `crate-checksums.txt`.
- **Desktop:** `Crate-macos-arm64.app.zip`, `Crate-macos-intel.app.zip`,
  `crate-windows.exe`, `crate-windows.msi`, `crate-linux.AppImage`, `crate-linux.deb` and
  `crate-linux.rpm`. Each is also at
  `https://github.com/thecrateapp/crate/releases/latest/download/<file>`. macOS builds
  are ad-hoc signed.
- **Android:** `crate.apk` (signed and minified), plus the versioned APK and App Bundle.
