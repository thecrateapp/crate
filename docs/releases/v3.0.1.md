# Crate 3.0.1

Crate 3.0.1 fixes problems found after the 3.0.0 release: an operator start that could stop the
stack, lyrics that disappeared after a provider error, playback that stalled when a preloaded
track's stream ticket expired, and two editions of an album merging into one. It needs no
database migration.

## Fixes

- **Crate Operator start no longer stops the stack.** The provenance proxy now reads its HAProxy
  config from a file; Compose rejected the inline config in read-only services and left the API
  and workers in Created. If an operator `up` still fails, `make agent-up` and the installer
  start the services it left created.
- **Deploys ship the agent tooling** with every release, and Redis keeps running after the
  recovery snapshot so the pinned deploy can start.
- **Operator alerts are quieter and readable.** Availability incidents wait five minutes and stay
  silent if they recover; messages state the condition, when it started or how long it lasted,
  and the key and revision `/crate_ack` takes, instead of raw evidence JSON.
- **Approval buttons arrive as soon as a plan is ready.** The worker sends a prepared plan to the
  bound human immediately. Read-only health and quality checks stay valid for an hour, and an
  expired plan says it must be prepared again.
- **Lyrics are no longer lost.** A provider 404, timeout or server error keeps the lyrics Crate
  already has, a worse result never replaces a better one, and the album Lyrics action revisits
  expired and missing entries.
- **Playback recovers from an expired stream ticket.** On web, desktop and iOS, a track that
  starts minutes after it was preloaded reloads with fresh credentials at the same position
  instead of stalling at 0:00.
- **Editions stay separate.** A canonical album folder no longer merges into a sibling edition
  that shares its MusicBrainz release group, such as a standard and a special edition.
- **Genre AI proposals** can be applied or discarded in Admin, and section saves settle the
  proposal.
- **No stray focus rings** on headings and dialogs after switching back to the app.

## New in Admin

- **Diagnose** on artist and album pages runs the artist health checks on demand and reports
  what it found.
- Two read-only checks report **overlapping editions** of one release and **tracks stored
  outside their album folder**. Dismissing an overlap you want to keep hides it for good.

## Downloads

- **Server:** `curl -fsSL https://cratemusic.app/install.sh | bash` for new home installs, or
  `crate install --dir <install folder>` to upgrade one. Binaries for Linux and macOS on amd64
  and arm64 are attached, with `crate-checksums.txt`.
- **Desktop:** `Crate-macos-arm64.app.zip`, `Crate-macos-intel.app.zip`, `crate-windows.exe`,
  `crate-windows.msi`, `crate-linux.AppImage`, `crate-linux.deb` and `crate-linux.rpm`. Each is
  also at `https://github.com/thecrateapp/crate/releases/latest/download/<file>`. macOS builds
  are ad-hoc signed.
- **Android:** `crate.apk` (signed and minified), plus the versioned APK and App Bundle.
