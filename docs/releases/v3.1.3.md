# Crate 3.1.3

Crate 3.1.3 documents observability end to end and gives it a place on cratemusic.app,
with the real Stack map. The site's home statement and manifesto are rewritten in
plainer prose, and the last Spanish pages on docs.cratemusic.app, the Smart Mix
references, are now in English. It has no database migration.

Crate is published under the GNU Affero General Public License v3.0 (AGPL-3.0).

## Documentation

- **Observability.** A new page explains what Crate observes and where each reading
  appears: System Health, the Stack map, Playback health, recommendation signals,
  product KPIs, Prometheus and Grafana, Operator alerts and the MCP tools. It also
  lists what telemetry never carries.
- **Metrics reference.** Every metric family with its type, unit, labels, Prometheus
  name and where it is shown, the recording rules and the Grafana dashboards. The
  page is generated from the metric catalogue and the monitoring configuration, and a
  test fails when it falls behind.
- **Monitoring** covers the application dashboards, the overlays that deploys keep,
  the shadow period and `make observability-grafana`.
- **Smart Mix.** The design, continuation plan and operations reference are in
  English.

## cratemusic.app

- **Observability chapter.** The 3D Stack map, captured from Admin with sample data,
  opens the chapter with its readings. It follows a playback event from Listen to an
  Operator alert and shows how a missing reading stays a gap instead of a zero.
- **Home.** A new lead, "Your server, drawn live", points to the chapter.
- **Plainer copy.** The home statement and the manifesto state their points directly.

## Downloads

- **Server:** `curl -fsSL https://cratemusic.app/install.sh | bash` for new home installs,
  or `crate install --dir <install folder>` to upgrade one. Binaries for Linux and macOS
  on amd64 and arm64 are attached, with `crate-checksums.txt`.
- **Desktop:** `Crate-macos-arm64.app.zip`, `Crate-macos-intel.app.zip`,
  `crate-windows.exe`, `crate-windows.msi`, `crate-linux.AppImage`, `crate-linux.deb` and
  `crate-linux.rpm`. Each is also at
  `https://github.com/thecrateapp/crate/releases/latest/download/<file>`. macOS builds
  are ad-hoc signed.
- **Android:** `crate.apk` (signed and minified), plus the versioned APK and App Bundle.
