# Crate 3.0.4

Crate 3.0.4 updates cratemusic.app and the technical documentation. The server and
the apps are the same as in 3.0.3, and it needs no database migration.

Crate is published under the GNU Affero General Public License v3.0 (AGPL-3.0).

## Website

- **A record shop behind every page.** A record shop after closing time now sits behind
  the whole site: in full behind the home hero, and dimmed wherever there is text to
  read.
- **The manifesto writes itself.** On the home page, the particle cloud that forms the
  Crate mark now flies into the three manifesto paragraphs, in reading order, and hands
  over to the real text once it has formed. The cloud is a real Crate library: 40,000
  tracks placed by how they sound.
- **The product comes before the install.** The home page now runs hero, manifesto,
  Inside Crate, Explore and then Get Crate, without the scroll hint or section counters.
- **Navigation links scramble on hover**, the same effect as the Copy button.
- **Inside Crate shows on phones again.** The section is taller than a phone screen and
  never revealed itself.

## Documentation

- **docs.cratemusic.app matches the website**: the same body typeface, the same
  navigation with Manifesto and Install, the record shop backdrop and the hover effect.

## Downloads

- **Server:** `curl -fsSL https://cratemusic.app/install.sh | bash` for new home installs,
  or `crate install --dir <install folder>` to upgrade one. Binaries for Linux and macOS
  on amd64 and arm64 are attached, with `crate-checksums.txt`.
- **Desktop:** `Crate-macos-arm64.app.zip`, `Crate-macos-intel.app.zip`,
  `crate-windows.exe`, `crate-windows.msi`, `crate-linux.AppImage`, `crate-linux.deb` and
  `crate-linux.rpm`. Each is also at
  `https://github.com/thecrateapp/crate/releases/latest/download/<file>`. macOS builds
  are ad-hoc signed.
- **Android:** `crate.apk` (signed and minified), plus the versioned APK and App Bundle.

Report issues at https://github.com/thecrateapp/crate/issues.
