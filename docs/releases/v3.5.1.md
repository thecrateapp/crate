# Crate 3.5.1

Crate 3.5.1 makes Google Cast work again in the Android and iOS apps: the Cast button no
longer stays disabled until a receiver happens to be discovered. It also adds the design for
Android Auto support. There are no server or database changes; the database stays at
migration 169.

Crate is published under the GNU Affero General Public License v3.0 (AGPL-3.0).

## Google Cast in the mobile apps

- **Casting starts again.** The Android and iOS apps offered Cast only once the Cast framework
  had already found a receiver. The framework only searches while the Cast dialog is open (and
  occasionally when the app comes to the foreground), so the target usually read "No Cast
  receivers found on this network" and the dialog that would have found them never opened.
  Cast is now offered whenever the Cast framework is available; the dialog searches and reports
  when it finds nothing.
- **Nearby-device permission.** A missing permission is still explained, but no longer disables
  Cast: starting a cast asks for it.
- **Web is unchanged.** Chrome discovers receivers on its own.
- **Known limit.** With Google's default receiver, which every build uses until Crate's own
  receiver is registered, a cast plays one track at a time. A queue that continues on the TV is
  planned.

## Project

- **Android Auto design.** `docs/plans/2026-11-28-android-auto-design.md` describes Android
  Auto support and the native foundation it shares with the default Cast receiver queue: a
  session-bound device credential, a compact device browse API, a Media3 library service and
  native play reporting.

## Upgrading

- Nothing to do on the server. The Cast fix needs the 3.5.1 Android or iOS app.

## Downloads

- **Server:** `curl -fsSL https://cratemusic.app/install.sh | bash` for new home installs,
  or `crate install --dir <install folder>` to upgrade one. Binaries for Linux and macOS
  on amd64 and arm64 are attached, with `crate-checksums.txt`.
- **Desktop:** `Crate-macos-arm64.app.zip`, `Crate-macos-intel.app.zip`,
  `crate-windows.exe`, `crate-windows.msi`, `crate-linux.AppImage`, `crate-linux.deb` and
  `crate-linux.rpm`. Each is also at
  `https://github.com/thecrateapp/crate/releases/latest/download/<file>`. macOS builds
  are ad-hoc signed.
- **Android:** `crate.apk` (signed and minified), plus the versioned APK and App Bundle.
