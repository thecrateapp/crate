# Crate 3.2.1

Crate 3.2.1 lets the installer set up monitoring for home installations: Prometheus,
Grafana and the exporters that feed the Stack map, System Health and the Grafana
dashboards. Monitoring stays optional and off by default. It has no database migration.

Crate is published under the GNU Affero General Public License v3.0 (AGPL-3.0).

## Monitoring from the installer

- **An optional step in `crate install`.** The wizard asks whether to set up monitoring,
  says what it costs (eight containers capped at 944 MiB of memory and 1 CPU, up to
  10 GB of disk) and that Grafana only listens on the server itself. It is unchecked by
  default. On systems where it cannot run yet (macOS, rootless Docker or an unsupported
  storage driver) the step says why instead of offering it.
- **`crate observability enable`, `disable` and `status`** turn monitoring on or off for
  an existing installation. Enabling it restarts Crate once. Disabling it stops the
  monitoring containers and keeps their history, dashboards and passwords for the next
  `enable`.
- **Unattended installs.** `--observability=on|off|keep` chooses the outcome, and
  `--yes` keeps whatever is already configured. The Grafana password is read from
  `CRATE_GRAFANA_PASSWORD` and never from the command line; when none is given, one is
  generated and shown once.
- **Upgrades.** A reinstall keeps monitoring running, restarts only the services whose
  configuration changed and copies Grafana's data before its image changes. An older
  installer never overwrites newer monitoring files.
- **No secrets in the clear.** The database account monitoring uses is created with a
  hashed password, has read-only monitoring rights and at most four connections.
- **`crate doctor`** reports monitoring in its own section and in `--json` under a new
  `monitoring` object. A missing monitoring network never stops Crate; doctor points it
  out instead.

## Upgrading

- Nothing changes until monitoring is turned on. Installations that already run their
  own monitoring as described in
  [Monitoring](https://docs.cratemusic.app/operations/monitoring) are not touched.

## Downloads

- **Server:** `curl -fsSL https://cratemusic.app/install.sh | bash` for new home installs,
  or `crate install --dir <install folder>` to upgrade one. Binaries for Linux and macOS
  on amd64 and arm64 are attached, with `crate-checksums.txt`.
- **Desktop:** `Crate-macos-arm64.app.zip`, `Crate-macos-intel.app.zip`,
  `crate-windows.exe`, `crate-windows.msi`, `crate-linux.AppImage`, `crate-linux.deb` and
  `crate-linux.rpm`. Each is also at
  `https://github.com/thecrateapp/crate/releases/latest/download/<file>`. macOS builds
  are ad-hoc signed.
- **Android:** `crate.apk` (signed and minified), plus the versioned APK and App Bundle.
