# Crate 3.2.4

Crate 3.2.4 brings the macOS desktop packages back. Crate 3.2.3 published them for
Windows, Linux and Android, but its macOS build stopped before packaging. The server is
the same as in 3.2.3: there is no database migration and nothing to change on upgrade.

Crate is published under the GNU Affero General Public License v3.0 (AGPL-3.0).

## Desktop

- **macOS is back.** The step that uploads the app's debug symbols to Sentry used a shell
  command the macOS build machines do not have, so 3.2.3 has no `Crate-macos-arm64.app.zip`
  or `Crate-macos-intel.app.zip`. The step now runs on the older shell those machines use,
  and a test keeps the desktop build free of commands it lacks.
- Everything else in [Crate 3.2.3](https://github.com/thecrateapp/crate/releases/tag/v3.2.3)
  applies: AI work in its own `ai` and `ai_bulk` queues, and the Windows packages.

## Upgrading

- No migration: the database stays at 144.
- A server already on 3.2.3 runs the same code and does not need to upgrade. Home installs
  can upgrade with `crate install --dir <install folder>` as usual.

## Downloads

- **Server:** `curl -fsSL https://cratemusic.app/install.sh | bash` for new home installs,
  or `crate install --dir <install folder>` to upgrade one. Binaries for Linux and macOS
  on amd64 and arm64 are attached, with `crate-checksums.txt`.
- **Desktop:** `Crate-macos-arm64.app.zip`, `Crate-macos-intel.app.zip`,
  `crate-windows.exe`, `crate-windows.msi`, `crate-linux.AppImage`, `crate-linux.deb` and
  `crate-linux.rpm`. Each is also at
  `https://github.com/thecrateapp/crate/releases/latest/download/<file>`. macOS builds
  are ad-hoc signed.
- **Android:** `crate.apk` (signed and minified), plus the versioned APK and App Bundle.
