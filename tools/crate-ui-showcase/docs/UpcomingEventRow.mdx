<DocHeading as="h2">Contract</DocHeading>

- A shared88px minimum row with injected artwork, details, date and actions. It does not fetch
  event data, manage attendance, decide release state or own a production router/controller.
- Identity uses a native button when `onToggle` is supplied, forwarding `expanded` as
  `aria-expanded`; otherwise a nonempty `href` uses a router Link with `openLabel`. With neither,
  identity is read-only. Toggle takes priority when both modes are supplied.
- Date and actions are sibling lanes outside the identity action:56px for date,112px for actions.
  An independent action never toggles or navigates identity. Empty lanes retain their widths.
- App-supplied details own meaningful names, wrapping and localization. Artwork geometry is
  supplied by the caller; the examples use actual MediaCover at88px, as the upcoming consumers do.
  The component retains its inset focus ring and minimum height without caller repairs.
