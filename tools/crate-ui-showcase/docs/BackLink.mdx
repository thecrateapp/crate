Native router navigation or callback Back control with preserved labels.

Back remains outside page identity; do not silently replace descriptive text with an arrow-only control. Listen consumers and PlaylistEditor use the same contract.

The approved mockup and Diego’s confirmed amendments are the visual reference. Shared components own their contracts; stories add layout only. Consumer adoption and native/AT/phase QA remain separate.
