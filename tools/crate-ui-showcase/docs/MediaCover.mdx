<DocHeading as="h2">Contract</DocHeading>

The approved existing frame has a quiet inset hairline and an accent-tinted fallback. Square/rounded/circle retain6px/16px/circular clipping. Standalone track/album/artist thumbnails enforce a48px minimum in both dimensions. Outer composition can enlarge them; MediaCover owns crop, clipping and fallback. Technical initials are uppercase JetBrains Mono40014px; a one-word title takes its first two characters, multiword titles first/last initials, missing text an em dash. A named absent image keeps the same accessible name; empty alt stays decorative. Native image loading is lazy with async decode. Native failure tries fallbackUrl, then content/icon/initials. Changing only fallbackUrl does not retry a failed primary. Native frame attributes/ref are forwarded.

renderImage receives canonical src/alt, image classes, a final-error callback and decorative fallback content. Managed transports own loading, ready preservation and credential recovery; they can retain the fallback until decoded and must not call the final-error callback for a recoverable credential change. AlbumCardArtwork adopts the shared frame while ArtworkSurface/CrateImage retains its existing lifecycle, responsive srcSet/sizes and lazy loading. This is a frame and lifecycle boundary, not an alternative API client.

The approved mockup and Diego's confirmed amendments are the visual reference. Stories mount
real shared components. Local1AV evidence is separate from adoption on all routes and native/AT QA.
