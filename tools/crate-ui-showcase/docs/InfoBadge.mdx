<DocHeading as="h2">Contract</DocHeading>

- Static information with semantic tones, default/overlay surfaces and a counter variant. No toggle semantics.
- 24 px height; JetBrains Mono 400 at 12/16 px; 1 px border, 3 × 8 px padding; counters use 6 px horizontal padding.
- Long text retains a custom tooltip; composed text can shrink without clipping child actions. OfflineBadge preserves states, icons, errors and compact presentation.

<DocHeading as="h2">Primary and tooltip review amendment</DocHeading>

Full metadata and explicit title detail use the shared custom Tooltip hint. They never emit a browser title or turn a static badge into a toggle. Visible values, icon colors and the 24px frame stay unchanged.

<DocHeading as="h2">Icon-only variant</DocHeading>

`variant="icon"` draws only the icon in a circle as wide as the badge is high (24 px, no
padding), with the tone's border and fill. Name it with `aria-label`, which also gives it the
`img` role; the tooltip shows `title`. Listen's Smart Mix mark uses it on phones once every track
of the playlist has stems, beside the `ready/total` label variant while it separates (approved
Smart Mix stems mockups, 2026-11-09).
