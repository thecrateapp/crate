<DocHeading as="h2">Contract</DocHeading>

Compact, default and wide densities keep the existing responsive column formulas and gap. Loaded media and GridSkeleton reserve the same column geometry. A finite positive `minItemWidth` opts into bounded auto-fill; invalid values fall back to density. Children retain their own native links and actions. Native root attributes, ARIA and refs are forwarded. A labelled root is a group; no grid keyboard interaction model is introduced.

The approved mockup and Diego's confirmed adjustments remain the reference. Initial adoption
and contract evidence do not certify every route or native/AT qualification.
