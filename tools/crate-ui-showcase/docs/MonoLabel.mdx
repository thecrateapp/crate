<DocHeading as="h2">Contract</DocHeading>

- Always uppercase, in both sizes and every layout. This includes the captions beside Checkbox, Switch and RadioGroup options; inline placement never creates a separate label style.
- The component applies CSS text-transform; callers pass natural text. The original children and metadata strings are not uppercased in JavaScript. The component's uppercase utility wins over a caller's normal-case, lowercase or capitalize utility.
- Use for contextual counts such as plays, albums, tracks, duration and match percentages, including ArtistCard subtitles and PlaylistCard metadata. Titles, artist names and prose retain their case; large highlighted metrics use StatNumber. Do not uppercase every generic EntityCard subtitle.
- `size=label|eyebrow`, a semantic `as`, `accent` and `meta`. Consumers must preserve its font, weight and case.
- Wrapping is supported. Scene wrappers constrain width without correcting component internals.
