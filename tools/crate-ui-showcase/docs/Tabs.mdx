<DocHeading as="h2">Contract</DocHeading>

Text tabs preserve the approved 1Q recipe: 2 px accent-action-hi underline, uppercase Mono labels,
roving focus, Home/End and orientation-aware arrow keys. Radix owns tab/tablist/tabpanel roles,
relationships, disabled choices and automatic activation. Both legacy variant names use this recipe.
Tabs select panels; they do not perform app navigation themselves.

Each app owns its URL helper. Unknown or empty values fall back without rewriting the link. A
valid change retains path, query (including repeated parameters), hash and location state. It pushes
history unless replace is requested. Repeated callbacks before the router renders coalesce into
one history entry. Back, Forward and external navigation remain authoritative. Pages with path
segments keep their adapters until their own phase; no mass page migration is included in 1AX.
The URL story exercises Listen's actual helper; Admin has its separate tested implementation.
