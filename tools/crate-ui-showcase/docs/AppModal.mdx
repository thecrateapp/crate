<DocHeading as="h2">Contract</DocHeading>

The existing 1N solid surface, header, body, footer and close control remain. Size, labels, mobile safe area and close gates belong to the facade. Nested Select/Tooltip portals remain above the panel and own their dismissal. Only the top custom modal handles Escape/Tab; locking modals and full-screen stories share the reference-counted `acquireBodyScrollLock` lifecycle. The document stays locked until the last owner closes, including navigation that unmounts a story before its global share modal. Releasing an owner twice is harmless. Focus returns to the owning trigger when it remains connected. Apps keep workflow, capability and busy state. Editable playlist fields use canonical controls; readonly fields retain FormField body typography and content-sized text, so long names/descriptions reserve their full height.

The approved mockup and Diego's confirmed adjustments remain the visual reference. Documented,
adopted and validated are separate statuses; broader native/AT/canonical QA remains pending.

ModalBody is the full-width content/scroll region, not a60ch prose column. Its width follows
the panel minus the panel border; children use the available width minus body padding. This
preserves the V2 artist biography at both desktop and mobile widths without a caller override.
The biography sample composes the actual ArtistBioProfile with the same AppModal as Listen.
