Ruled unfilled figure or section, shared label, metadata, status, description and actions.

A top quiet1px rule,22px top inset and20px header-to-content space; ruled=false removes only the rule. Figure is default; section is explicit. MonoLabel owns the uppercase caption and headingLevel optionally promotes it to h2/h3. The visible label names the container even without a heading; summary retains the explicit accessible-name override. Description is associated with the panel, remains outside status announcements and uses IBM Plex Sans14/20. Metadata stays contextual and status alone is polite. Actions are injected controls, not MonoLabel content; text/measurement changes do not announce as status. Neither an all-purpose filled panel nor a replacement for every card.

`label.tone="accent"` delegates the complete section-heading foreground to MonoLabel. Description, metadata, status and actions retain their own colors and semantics; the default heading tone remains subtle. Settings uses this variant without caller color overrides.

The approved persistent mockup and confirmed amendments are the reference. Scene layout never repairs component internals.
