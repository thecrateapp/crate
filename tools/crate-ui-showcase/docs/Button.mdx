<DocHeading as="h2">Contract</DocHeading>

Text actions, explicit confirmation and semantic native links. Seven semantic variants share the mockup typography and sizing recipe: Roboto 500, default 14px, rectangular 4px corners or an explicit pill. Fine heights xs24/sm32/default40/lg44; coarse targets reserve at least44px in layout. Icon sizes remain compatibility options; named ActionButton is preferred for conventional item/header actions. Native form type, ref and enabled router child handlers are preserved. Disabled/loading links stay named links, leave Tab order and block pointer/keyboard navigation and both child/caller handlers. Loading buttons show one decorative spinner, stay named and block repeat execution.

Neutral icon-only sizes (ghost, outline and secondary) keep their background unchanged on hover and highlight the foreground with high accent. Conventional ActionButton/ActionLink inherit this rule. Text-button hover and specialized filled playback controls retain their own roles. No caller hover-fill overrides.

The approved persistent mockup and Diego’s confirmed adjustments are the reference. Shared components own their geometry, states and typography. Stories add layout only.

<DocHeading as="h2">Primary and tooltip review amendment</DocHeading>

Trial requested by Diego: the default primary variant uses a 1px accent border, accent text/icons and a transparent background in resting and hover states. Heights, shape, typography, loading and disabled/link semantics stay governed by Button. A supplied title becomes a custom Tooltip hint, never a DOM title; an outer Tooltip owns the description when present.

Icon-only compatibility controls that previously relied on a title retain that name through aria-label; named text actions keep their visible label. The title metadata is exclusively a custom hint.
