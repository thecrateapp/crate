<DocHeading as="h2">Contract</DocHeading>

- Search field with optional clear action and controlled or uncontrolled value.
- Uses Input geometry/type. The clear action retains keyboard focus in the search input and a 32 px fine / 44 px coarse target.
- Debounce defaults to 300 ms, clears immediately and suppresses partial IME composition. A readonly or disabled query has no mutating clear action. Apps provide translated labels and API behavior.
- The approved persistent mockup and Diego's confirmed adjustments are the visual reference. Examples import the actual component; scene CSS does not repair its internals.
