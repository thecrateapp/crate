<DocHeading as="h2">Contract</DocHeading>

Compact round controls with semantic default/primary/danger tones, icon-only accessible label and native title. Fine sizes32/40/44 with glyph16/18/20; coarse minimum44px is real layout space, never overlapping pseudo-targets. Pressed state and optional active highlighting are separate: active does not invent aria-pressed. Loading disables, marks busy and replaces the glyph with a decorative spinner. Shared global focus and reduced-motion rules apply. Preserve existing round/glow controls; ActionButton is the approved rectangular header/row composition. Card artwork surface now uses the opaque object surface and quiet border, without shadow/backdrop (1AT). No player ring/beam/volume changes.

The approved persistent mockup and Diego’s confirmed adjustments are the reference. Shared components own their geometry, states and typography. Stories add layout only.
