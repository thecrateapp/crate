<DocHeading as="h2">Contract</DocHeading>

Controlled action menu with shared media/user headers, separators, disabled/danger actions and disclosures. Callers retain action authority, localized labels and authenticated image adapters. The controller owns trigger/pointer anchoring, viewport clamping, outside dismissal and scroll handling. Native menu navigation supports arrows, Home/End, Escape and nested disclosure navigation; closing restores the invoking focus.

Wide web windows with a fine primary pointer and hover use the anchored desktop menu. A reported touchscreen capacity alone does not override those primary input capabilities: Chrome can report touch points on an ordinary desktop. Coarse/touch-first input, narrow layouts and Capacitor keep the mobile action sheet, including its drag dismissal. Keyboard access remains available in both presentations. This correction does not change the global layout breakpoint, pointer target sizes or native runtime policy.

Fixed solid overlay chrome, canonical AppMenuButton typography/focus and StatusDot remain shared. Desktop menus portal above content; mobile sheets own backdrop, scroll lock, safe area and focus containment. The approved mockup and later confirmed adjustments remain the visual reference. Geometry, touch and desktop modes are exercised in both review hosts. Device/AT certification remains a separate phase.

### 1BD approved option labels

Action options and disclosure/submenu options now render the actual uppercase MonoLabel,
at its existing 11px/15.4px role. Their foreground inherits the menu state, preserving normal,
active, danger and disabled treatments. Media/user headings, names, details and group headings
retain their existing roles. Two-line wrapping, measured full-label custom tooltips, original localized
accessible names, pointer targets and keyboard navigation remain intact in desktop menus and
mobile action sheets. Diego approved this typography on 2026-10-20; menu authority is unchanged.

See Reviews/1BD/Action labels and the matching standalone preview for section navigation and
menu options together.

Enabled MonoLabel options change their foreground to high accent on hover, keyboard focus,
highlight and open disclosure, without a background fill. Normal/active/danger resting states
are preserved; disabled options do not acquire an accent hover. This applies to nested menus
and touch sheets through the shared recipe, with no per-caller state selectors.
