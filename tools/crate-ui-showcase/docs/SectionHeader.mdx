Existing props and heading levels remain compatible. General panels use InstrumentPanel.

The approved mockup and Diego’s confirmed amendments are the visual reference. Shared components own their contracts; stories add layout only. Consumer adoption and native/AT/phase QA remain separate.

### 1BD approved section-action labels

The default section action uses an accent uppercase MonoLabel and a decorative StatusDot with
the shared accent glow, replacing the arrow. `SectionActionLabel` owns this composition and is
also used inside injected native links and Listen's search footer. The standard English label
is **View All**; localization remains the caller's responsibility. Button/link semantics,
44px hit height, callbacks and keyboard focus remain unchanged. The dot has no accessible name
and no pulse. Names, headings and descriptive text keep their original case.

`SectionActionButton` owns the native callback form of this pattern. It has no horizontal
padding, so contextual actions such as the artist biography's **Show more** align with the
preceding text. It retains a44px hit height, native refs/disabled behavior and visible keyboard
focus, without a background fill or hover underline. Keep the contextual action's own label;
only collection navigation uses **View All**. Biography More/Less uses the same component.
