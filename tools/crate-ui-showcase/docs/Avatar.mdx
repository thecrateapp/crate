Name uses first/last initials, including Unicode; one-word names use one initial and missing names use ?. Explicit empty alt is decorative. A failed source falls back; a different source can load. Native span attributes/ref forward. renderImage keeps authenticated transport in the app and supplies its final-error callback; the app owns retry before calling it. UserAvatar already adopts this contract through EntityAvatar and CrateImage; no user-size change is made.
